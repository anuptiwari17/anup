# Anup Tiwari — Portfolio

Personal portfolio website showcasing work as a Software Developer.

## Overview

### Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- Base UI
- Motion

### Features

- Light & dark theme interface
- Mobile-first responsive design
- vCard integration
- Installable as PWA
- Sound effects & haptics support
- SEO optimized (JSON-LD, sitemap, robots)
