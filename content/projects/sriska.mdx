# Sriska

Sriska is a modern, dark-themed Software Asset Management (SAM) platform frontend crafted with an emphasis on visual hierarchy, fluid micro-interactions, and motion design.

## Links

- **Live Platform**: [samorg.vercel.app](https://samorg.vercel.app/)
- **Source Code**: [github.com/anuptiwari17/sam](https://github.com/anuptiwari17/sam)

## Overview

Software Asset Management interfaces are traditionally dense, utilitarian, and visually fatiguing. Sriska redesigns this paradigm by blending high-density asset data presentation with an ultra-refined dark aesthetic, continuous spatial cues, and choreographic motion. Every transition and state change is smoothed to reduce cognitive load while navigating complex asset rosters, license compliance statuses, and system utilization metrics.

## Key Features

- **Dark-Themed Premium UI Design**: High-contrast, tailored dark palette built for long sessions with balanced neon accents and clean typography.
- **Smooth Page Transitions & Animations**: Kinetic screen transitions and layout animations powered by Framer Motion.
- **Choreographed Micro-Interactions**: High-performance timeline and scroll animations orchestrated with GSAP.
- **Asset Hierarchy & Status Tracking**: Clean visualizations for monitoring enterprise software licenses, compliance status, and operational lifecycle stages.
- **Responsive Layout Architecture**: Fluid multi-breakpoint layout optimized for both wide workstation displays and compact viewports.

## Tech Stack

- **Framework**: React.js
- **Animation & Motion**: GSAP, Framer Motion
- **Styling**: Tailwind CSS
- **Iconography**: Lucide-React
- **Deployment**: Vercel
